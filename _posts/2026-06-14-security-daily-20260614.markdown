## 今日高危 CVE 速览

### 🔥 DbGate 系列 RCE（3个漏洞）

**CVE-2026-48017 (CVSS 8.8)** · **CVE-2026-47670 (CVSS 9.5)** · **CVE-2026-47669 (CVSS 9.5)**

DbGate loadReader 端点 functionName 代码注入 RCE。process.binding("spawn_sync") 和 import() 两种方式绕过 require=null 沙箱。同一项目的 Zip Slip 实现零认证任意文件写。详见今日深度分析。

### Twig 沙箱逃逸

**CVE-2026-47732 (CVSS 7.5)** · **CVE-2026-24425 (CVSS 8.8)**

SandboxNodeVisitor 对隐式 __toString() 调用不做 checkMethodAllowed 检查，导致沙箱逃逸。影响所有使用 Twig sandbox 的 Symfony 项目。

### Puma PROXY Protocol

**CVE-2026-47737** · **CVE-2026-47736** (CVSS 7.5)

PROXY Protocol v1 解析器在持久连接上接受重复协议头，导致源IP伪造和远程内存耗尽。影响所有使用 proxy_protocol 的 Puma 部署。

### NASA AMMOS Toolkit

**CVE-2026-47731 (CVSS 9.1)**

Binary Stream Capture (BSC) 组件暴露无认证 HTTP API，路径穿越导致任意文件读取。NASA 的空间任务工具也存在安全漏洞。
